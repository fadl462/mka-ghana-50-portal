MKA GHANA @ 50 — REVIEWER PASSWORD LOGIN

This package changes reviewer sign-in from email OTP to administrator-issued email/password authentication. No Resend account, API key, sender domain, or email delivery service is required for reviewer login.

SECURITY AND ACCESS
1. Public/self-service reviewer registration is disabled.
2. Only active judge accounts present in reviewer_allowlist can sign in.
3. Login attempts are rate-limited.
4. Passwords are verified using PBKDF2-SHA256 with 150,000 iterations and unique salts.
5. Reviewer sessions are signed using the existing SESSION_SECRET.
6. Existing administrator login, assignments, evaluations and feedback are preserved.
7. The previous OTP migration (0007) remains in migration history because it may already have been applied. Its OTP tables are no longer used for reviewer sign-in.

DEPLOYMENT
1. Back up the production D1 database before applying the migration.
2. Apply the new migration:
   npx.cmd wrangler d1 migrations apply mka-ghana-50 --remote
3. Deploy the Worker:
   npx.cmd wrangler deploy

Run both commands from the extracted project folder. Use npx.cmd in Windows PowerShell.

TEST
1. Open https://mka-ghana-50-portal.workers.dev/judges
2. Sign in using the authorised email and the initial password you supplied.
3. Confirm the Reviewer Workspace opens and the assigned entries load.
4. Sign out, then confirm an unauthorised email cannot sign in.

ADDING THE OTHER REVIEWERS
The existing protected administrator API endpoint POST /api/admin/judges creates a judge account and adds the email to reviewer_allowlist. It requires a Super Administrator session and a password of at least 12 characters. No public registration page is provided.

EMAIL NOTIFICATIONS TO CONTESTANTS
Reviewer login no longer depends on Resend. However, sending automatic email alerts to contestants when reviewer feedback is published still requires an email delivery provider. Without one, feedback remains visible through Track Your Entry, but an email alert cannot be sent. This is separate from reviewer sign-in.
