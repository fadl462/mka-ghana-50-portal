MKA GHANA @ 50 — REFRESH STATE AND WITHDRAWAL REMOVAL

Files in this ZIP are replacements for the matching paths in the existing project.

CHANGES
1. Opening an artwork adds its entry ID, current page, sort order and search term to the page URL.
2. Refreshing while an artwork is open restores the same artwork viewer.
3. Closing the viewer removes only the entry parameter and leaves the gallery page/search/sort state intact.
4. The previous/next viewer navigation continues to update the URL so refresh restores the currently viewed artwork.
5. Removed the public withdrawal workflow and its Worker endpoint.
6. New submissions no longer generate or store private withdrawal-owner tokens.
7. Removed withdrawal controls and withdrawal instructions from Track Your Entry.
8. Removed the Withdrawn option from the administrator's submission-status selector.

DEPLOYMENT
- Replace only the listed files in the existing project.
- Deploy the updated Worker as well as the updated public files.
- No database migration is required.
- Existing records previously marked withdrawn remain in the database for historical/audit integrity; this update does not restore them.
- Existing submissions, evaluations, reviewer feedback, likes and judge assignments are preserved.
